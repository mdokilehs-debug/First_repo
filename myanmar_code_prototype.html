🇲🇲 မြန်မာကုဒ်

မြန်မာလို အမိန့်ရေးပြီး စမ်းသပ်ကြည့်ပါ — ဗားရှင်း ၀.၁

ပထမဆုံး လုပ်ဆောင်ချက်

ဒီနမူနာက မြန်မာ Code အနည်းငယ်ကို ဖတ်ပြီး ရလဒ်ပြပေးပါတယ်။ အောက်က Code ကို ပြင်ပြီး “▶ လုပ်ဆောင်မယ်” ကို နှိပ်ပါ။

ဒီနေရာမှာ ရလဒ်ပေါ်လာပါမယ်။
လက်ရှိ နားလည်တဲ့ အမိန့်များ
  • အမည် = "စာသား" — တန်ဖိုးသိမ်းရန်
  • ပြပါ("မင်္ဂလာပါ") — စာသားပြရန်
  • ပြပါ("မင်္ဂလာပါ " + အမည်) — စာသားနဲ့ သိမ်းထားတဲ့ တန်ဖိုးကို ပေါင်းပြရန်

သတိပြုရန် — ဒါက စမ်းသပ်ဗားရှင်းသာ ဖြစ်ပါတယ်။ Android APK ထုတ်ပေးတဲ့စနစ် မပါသေးပါ။ နောက်အဆင့်တွေမှာ အမိန့်များ၊ UI ဖန်တီးခြင်းနဲ့ APK build စနစ်ကို တိုးချဲ့ရပါမယ်။
